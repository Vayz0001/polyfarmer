# Polyfarmer brand assets

The Polyfarmer mark is a blue stem with a green leaf: a "P" that grows. It is original artwork released under
the project's [MIT license](../../LICENSE), like the rest of the repository.

| File | Background | Use it for |
| --- | --- | --- |
| [`polyfarmer-mark.svg`](polyfarmer-mark.svg) | Transparent | The README header, slides, docs, anywhere you set your own background. |
| [`polyfarmer-navy.svg`](polyfarmer-navy.svg) | Dark blue tile (`#0e1530`) | Favicons, app icons, avatars. The dashboard favicon is this one. |
| [`polyfarmer-black.svg`](polyfarmer-black.svg) | Black tile (`#0a0c10`, the dashboard background) | Dark pages and banners where the navy tile would show an edge. |

## Using the mark

- Keep clear space around it of at least the width of the stem.
- Use the artwork as it is. Don't recolour, rotate, stretch or add effects.
- Use the transparent mark on backgrounds where blue and green both stay readable (white, light grey, or the
  dark dashboard background). On anything else, use a tile.
- Polyfarmer is an independent project and is not affiliated with Polymarket. Don't combine the mark with
  Polymarket's logo in a way that suggests otherwise.
